# Security Policy

## Supported deployment

Security fixes target the current `main` branch and the documented single-node
private-beta deployment. Development mode is trusted-local only and must not be
published to an untrusted network.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/nguoimoihoccode/nexus-agent/security/advisories/new).
Do not open a public issue with exploit details, credentials, private user data, or
environment contents.

Include the affected commit, deployment profile, reproducible impact, and the
smallest safe proof of concept. Never include active tokens or unrelated tenant data.

## Response expectations

The maintainer will acknowledge a complete report, validate severity, coordinate a
fix, and publish remediation guidance when disclosure is safe. No bounty or formal
response-time SLA is currently offered.
